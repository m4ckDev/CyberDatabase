## What I build

My work is centered on practical cybersecurity engineering and software development:

- **Cybersecurity tooling and research** — offensive and defensive security labs, automation, OSINT, CTI, auditing, and technical documentation.
- **Linux systems** — security workstations, Parrot OS customization, networking, VPNs, and lab infrastructure.
- **Android / Google Pixel** — kernel modules, NetHunter, external wireless hardware, monitor mode, and reproducible device modifications.
- **iOS applications** — native apps, App Store deployment, Swift/SwiftUI, and product development.
- **Automation and infrastructure** — Python, APIs, servers, deployment workflows, and self-hosted systems.
