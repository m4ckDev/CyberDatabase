## PowerShell Quick Reference

```powershell
Get-ComputerInfo
Get-NetIPAddress
Get-NetRoute
Get-NetTCPConnection
Get-Process
Get-Service
Get-WinEvent -LogName System -MaxEvents 20
```

## Security Checks

```powershell
Get-NetFirewallProfile
Get-MpComputerStatus
Get-LocalUser
Get-LocalGroup
```
