# Cybersecurity Hardware Directory

A curated purchasing and reference directory for security-research, networking, wireless, RFID/NFC, SDR, USB, physical-security, embedded, and lab hardware.

Use hardware only on systems, devices, facilities, locks, RF environments, and networks you own or are explicitly authorized to test. Product availability, export restrictions, shipping, and local laws vary by region.
