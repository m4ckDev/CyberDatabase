# Open-Source Intelligence (OSINT)

CyberDatabase uses OSINT for lawful research, defensive security, incident response, exposure review, verification, due diligence, and authorized investigations.

## Core workflow

1. Define the question before collecting data.
2. Record the initial public indicator or source.
3. Preserve volatile evidence before pivoting.
4. Prefer passive collection before interacting with a target.
5. Use multiple independent sources for important claims.
6. Separate facts, correlations, assumptions, and attribution.
7. Record collection time, source, tool, confidence, and limitations.
8. Convert results into useful outputs such as IOC enrichment, exposure findings, timelines, ATT&CK mappings, detection ideas, or investigative leads.

## Common OSINT areas

- Domains, DNS, certificates and public infrastructure
- IP and service exposure
- Threat intelligence and reputation
- Companies, filings and public records
- People, usernames and public social-media activity
- Historical web content and archives
- Image and video verification
- Geolocation, maps and satellite context
- Documents and metadata
- Public code and software repositories
- Breach-awareness and exposure research using lawful sources
- News, narrative and media monitoring

## Evidence standard

```text
Objective
Starting indicator
Source URL
Collected at
Tool/service
Observation
Corroborating source(s)
Confidence
Limitations
Security significance
Follow-up action
```

## Responsible use

Publicly discoverable information can still be sensitive. Minimize collection to what is necessary, respect privacy and legal boundaries, and do not bypass authentication or access controls under the label of OSINT.
