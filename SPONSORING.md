# Support m4ckDev

If the open-source projects, research, documentation, or tooling maintained under **m4ckDev** have been useful to you, you can support continued development through GitHub Sponsors:

**https://github.com/sponsors/m4ckDev**

## What sponsorship supports

Sponsorship helps fund the practical costs behind independent development and security research, including:

- open-source cybersecurity tooling and documentation;
- Linux, Android, and Google Pixel security development;
- test hardware, adapters, devices, and lab infrastructure;
- OSINT and cyber threat-intelligence resource maintenance;
- application development and testing;
- hosting, domains, CI/CD, and other development infrastructure;
- time spent documenting reproducible technical work for others.

## Sponsorship status

The repositories are configured with GitHub's standard `.github/FUNDING.yml` using the `m4ckDev` GitHub Sponsors account.

GitHub controls enrollment, identity verification, payment/tax setup, approval, and when the Sponsor button becomes active. Until GitHub Sponsors approval is complete, the sponsorship URL may not yet accept payments.

Thank you for supporting independent open-source development and security research.
