# CyberDeck Mobile

Native Expo source scaffold.

API default:

http://192.168.0.124:8000

Development from a Mac:

1. Copy this folder to the Mac or Git repository.
2. Run npm install.
3. Run npx expo install --fix.
4. Run npx expo start.
5. Use EAS for TestFlight builds when Apple Developer credentials are ready.

The full responsive CyberDeck web interface is also installable as a PWA from Safari.
