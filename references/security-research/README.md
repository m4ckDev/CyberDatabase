# External Security Research Sources

This directory catalogs external security resources that complement CyberDatabase-owned documentation and the synchronized HackTricks reference mirror.

Each source has its own subdirectory so provenance, scope, links, and usage notes remain separate from CyberDatabase-authored material.

## Sources

- [`payloads-site/`](payloads-site/README.md) — web-application payload reference for authorized testing and validation.
- [`vx-underground/`](vx-underground/README.md) — malware research, papers, defensive research, YARA material, platform-specific research, and threat-analysis archives.

## Policy

External resources are linked and summarized rather than represented as CyberDatabase-authored work. Original licenses, attribution, and site terms remain with the source projects. Malware samples and other hazardous binaries are not mirrored into CyberDatabase; analysis notes, papers, defensive references, and research links are indexed instead.
